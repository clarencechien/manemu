# M4 真機 dogfood 劇本(W5 生成,2026-07-29)

用法:兩人一組(一人扮旅客講中文、一人扮日方看譯文/聽譯音),照台詞走,
每輪記錄:逐字稿對不對、譯文對不對、回譯有沒有讓你抓到錯、體感延遲(碼表)。
檢核點 = 該輪的「埋雷」,對應 harness 的錯誤型態。

| 3 | 旅客 | 不對,我這裡有訂房確認信,上面寫得很清楚是兩晚,從今天到後天退房。 | 傳達旅客持有書面證明(確認信),且明確指出入住到退房的日期範圍為兩晚 | 問尾(退房日期的表達方式需清楚,避免被誤譯成單一日期) |

## 藥局買藥(症狀描述+過敏史)
